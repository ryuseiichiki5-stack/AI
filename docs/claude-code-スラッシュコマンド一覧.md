# Claude Code スラッシュコマンド一覧

作成日：2026-10-03

## この資料について

- スラッシュコマンド（`/` で始めて入力する操作の呼び出し）の一覧です。
- 竜生さん向けに、専門用語（難しい言葉）には括弧で意味を添えています。
- 見直すときは、まず「よく使う7つ」を見てください。

## 先に結論

- 迷ったら `/help`（使い方の案内を出す）を打ちます。
- 最新で正確な一覧は、画面上の `/help` が一番確かです。
- この資料は、作成時点で確認できたものをまとめた控えです。

## よく使う7つ

| コマンド | 一言でいうと |
|---|---|
| `/help` | 使い方を表示する |
| `/clear` | 会話をリセットする（新しく始める） |
| `/compact` | 長い会話を要約して短くする |
| `/context` | 会話の容量（どれだけ使ったか）を見る |
| `/model` | 使うAI（モデル）を切り替える |
| `/resume` | 前の会話の続きを始める |
| `/init` | CLAUDE.md（AIへの指示書）を作る |

## 基本の操作

| コマンド | できること | 使う場面 |
|---|---|---|
| `/help` | 使い方とコマンドの案内を出す | 困ったとき |
| `/clear` | 会話を空にして新しく始める | 話題を変えるとき |
| `/compact` | 会話を要約して容量を空ける | 会話が長くなったとき |
| `/context` | 容量（トークン（AIが読む文字の単位））の使用状況を見る | 容量が心配なとき |
| `/resume` | 過去の会話を選んで再開する | 昨日の続きをしたいとき |
| `/model` | モデル（AIの種類）を切り替える | 速さ重視か、賢さ重視かを変えたいとき |
| `/fast` | 高速モード（出力が速くなる設定）を入れ切りする | 返答を速くしたいとき |
| `/config` | 設定画面を開く | 見た目などの設定をしたいとき |

## 作業を助ける道具（スキル）

スキル（決まった作業の手順書）は、`/名前` で呼び出せます。
下の表は、今回のこの環境で使えると確認できたものです。

| コマンド | できること |
|---|---|
| `/init` | CLAUDE.md（AIへの指示書）を新しく作る |
| `/code-review` | 変更内容のミスを点検する（レビュー（見直し）） |
| `/security-review` | 安全面（情報漏れなど）の点検をする |
| `/simplify` | 変更したコードを分かりやすく整える |
| `/loop` | 同じ作業を一定間隔で繰り返す |
| `/run` | 作ったアプリを実際に動かして確認する |
| `/update-config` | 設定ファイル（settings.json）を変更する |
| `/keybindings-help` | キーボードのショートカット（近道キー）を変更する |
| `/fewer-permission-prompts` | 許可の確認画面が出る回数を減らす |
| `/claude-api` | Claude API（AIを自分のアプリから使う仕組み）の案内 |
| `/docs` | 共有・編集できる文書を作る |
| `/docx` | Word（ワード）形式のファイルを作る・読む |
| `/pdf` | PDF（閲覧用の文書ファイル）を作る・読む |
| `/pptx` | PowerPoint（スライド資料）形式のファイルを作る・読む |
| `/xlsx` | Excel（エクセル）形式の表を作る・読む |
| `/morning` | 朝のまとめ表示を作る |

## 注意点

- 一覧は、バージョン（版）が上がると変わることがあります。
- 表の「できること」は、名前と説明文から書いています。
- 実際の動きは、一度試して確かめてください。
- 「分からない」点：全コマンドの完全な一覧は、この環境からは取得できませんでした。

## 見直し方

1. Claude Code の画面で `/help` と入力します。
2. この表に無いコマンドが出たら、追加を依頼してください。
